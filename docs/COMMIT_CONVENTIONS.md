# Commit messages

Use concise English commit subjects describing the change and its purpose.

Format: `type(scope): imperative summary` (scope is optional).

Types: `feat`, `fix`, `docs`, `refactor`, `test`, `chore`, `build`, `ci`, `perf`.

Examples:
- `feat(api): add prediction endpoint`
- `fix(config): resolve model paths from project root`
- `docs: clarify installation steps`

Keep each commit focused. Avoid vague subjects such as `Update project`, `Link`, or `Push`.
Preserve existing authorship and co-author trailers. Do not rewrite published history solely to restyle commit messages.
Never commit credentials, local environment files, or generated private data.
