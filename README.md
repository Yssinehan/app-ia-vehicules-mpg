# Vehicle Fuel Efficiency Analyzer

A Streamlit application for exploring vehicle fuel efficiency in miles per gallon (MPG).

## Live demo

https://app-ia-vehicules-mpg.streamlit.app/

## Installation

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Project files

- `app.py` — Streamlit application
- `requirements.txt` — Python dependencies
- `.gitignore` — excluded local files

## About

An educational Python project for interactive analysis of vehicle MPG data.
